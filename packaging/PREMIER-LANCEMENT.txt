STUDIO IA — version Windows V0 (ALPHA expérimentale)

LANCEMENT
1. Extraire tout le ZIP dans un dossier (ex. Documents\STUDIO-IA), sans séparer _internal.
2. Double-cliquer sur Lancer-STUDIO-IA.cmd (ou STUDIO-IA.exe).
3. Ouvrir l'onglet « Matériel et diagnostic » : il indique ce que ce PC peut faire
   (processeur, mémoire, disque, carte graphique, restauration IA possible ou non).

RESTORE (restauration vidéo)
- Nécessite FFmpeg et ffprobe (non inclus, aucun téléchargement automatique).
  Le plus simple : placer ffmpeg.exe et ffprobe.exe dans le sous-dossier ffmpeg\bin\
  de ce dossier, ou utiliser le bouton « Chemins FFmpeg… ».
- Importer une vidéo, choisir Préservation, choisir une nouvelle destination,
  cliquer « Vérifier le plan » puis « Démarrer ». L'original n'est jamais modifié.
- Comparaison : curseur avant/après, molette ou boutons pour zoomer (synchronisé),
  glisser pour se déplacer, « Exporter la comparaison… » pour une image côte à côte.
- Restauration IA : seulement avec une carte graphique Vulkan et les modèles officiels
  fournis séparément (voir docs/PLAN-POCO-VERS-PC.md, « Jour J »). Sinon, le mode CPU
  classique reste disponible.

CREATE (scènes et caméras)
- Fonctionne SANS Unreal Engine : générer une ville, choisir les caméras, voir le plan,
  enregistrer la scène, créer un projet Unreal prêt à ouvrir.
- Avec Unreal Engine 5.6 à 5.8 installé séparément : bouton « Construire dans Unreal »
  (expérimental, NON TESTÉ). Aucun rendu Unreal n'est annoncé tant qu'il n'est pas vérifié.

PARAMÈTRES, PROJETS, JOURNAUX
- Conservés dans %LOCALAPPDATA%\STUDIO-IA (bouton « Ouvrir le dossier des journaux
  et projets »). Supprimer le dossier de l'application ne les efface pas.
- Désinstaller : supprimer simplement le dossier extrait.

Voir INSTALLER.md pour les plateformes testées et les limites.
