# Mission 004 — documents de préparation

[Cahier technique](CAHIER-TECHNIQUE.md) et [sources consultées](sources.json).

Le schéma `model-manifest-v2.schema.json` décrit un **contrat futur**, pas une API
déjà implémentée. Le registre courant de V1 utilise son contrat initial ; une
migration/validation sera nécessaire en M004. Aucun manifeste fictif de modèle
installé n'est fourni et aucun fichier de poids n'a été téléchargé.

Ces documents ne lancent pas la Mission 004. Ils conditionnent sa mise en œuvre
à la qualification de la version CPU actuelle et à l'accord du propriétaire.
