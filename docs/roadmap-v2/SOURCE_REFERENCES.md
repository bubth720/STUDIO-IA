# Références techniques officielles (à revisiter lors de chaque exécution)

- Video2X : https://github.com/k4yt3x/video2x ; https://github.com/k4yt3x/video2x/releases
- Real-ESRGAN : https://github.com/xinntao/Real-ESRGAN
- RIFE : https://github.com/hzwer/ECCV2022-RIFE ; NCNN https://github.com/nihui/rife-ncnn-vulkan
- Anime4K : https://github.com/bloc97/Anime4K
- FFmpeg filtres, zscale, libplacebo, bwdif, libvmaf : https://ffmpeg.org/ffmpeg-filters.html
- FFprobe : https://ffmpeg.org/ffprobe.html
- PySide6 / Qt : https://doc.qt.io/qtforpython-6/

**Important** : version, options de CLI, licence des poids, CPU AVX2, GPU Vulkan, notices et intégrité doivent être revérifiés à la date de chaque mission. Une documentation, même officielle, ne remplace pas un test local sur la version installée.
